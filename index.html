🚀 GitHub Pages 무료 인터넷 URI(주소) 배포 가이드

내 대시보드를 인터넷에 올려 고유 웹 주소로 사용하는 3단계 방법

1단계: GitHub에 새로운 저장소(Repository) 생성하기

  1. GitHub.com 로그인 후 우측 상단의 + → New repository를 클릭합니다.
  2. Repository name에 원하는 이름(예: macro-dashboard)을 입력합니다.
  3. Public(공개)으로 설정하고 하단의 Create repository 버튼을 누릅니다.

2단계: 터미널에서 코드 업로드하기

맥북 터미널에서 아래 명령어를 순서대로 실행합니다:

cd /Users/insooshin/Desktop/macro-dashboard
git init
git add .
git commit -m "Deploy: Global Macro Dashboard 5x3"
git branch -M main
git remote add origin https://github.com/<사용자아이디>/macro-dashboard.git
git push -u origin main

* 터미널 사용이 익숙하지 않으시면 GitHub 웹사이트에서 'uploading an existing file'을 눌러 해당 폴더의 파일들을 마우스로 끌어다 놓으셔도 됩니다!

3단계: GitHub Pages 켜고 나만의 URI(웹 주소) 확인하기

  1. 저장소 상단 메뉴에서 Settings(설정) → 좌측 Pages 메뉴를 클릭합니다.
  2. Build and deployment → Branch에서 main 브랜치와 / (root) 폴더를 선택하고 Save를 누릅니다.
  3. 약 1분 후 상단에 "Your site is live at https://<내아이디>.github.io/macro-dashboard/" 라는 나만의 인터넷 고유 URI 주소가 발급됩니다!
  4. 이 주소를 스마트폰 카카오톡으로 전송하여 사파리나 크롬에서 열고 '홈 화면에 추가'하시면 모바일 전용 앱처럼 사용하실 수 있습니다!
