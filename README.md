# 🌐 글로벌 매크로 경제 5x3 대시보드 (Global Macro Dashboard)

실시간 주요국(미국·일본·한국·중국·유럽) 국채금리, 환율, 기준금리, 통화량(M1, M2), 근원물가지수, 물가상승률, 실업률을 5x3(15칸) 격자로 한눈에 모니터링하고, 항목 클릭 시 **50년간(1975~2026년)의 역사적 시계열 차트**를 마우스 휠 및 드래그로 확대/축소(Zoom & Pan)하여 분석할 수 있는 웹 대시보드입니다.

상단에 **카카오톡 전송 버튼**과 **이메일 전송 버튼**이 탑재되어 있어 원클릭으로 현재 매크로 시황과 대시보드 링크를 공유할 수 있으며, **GitHub Pages**를 통해 나만의 무료 인터넷 고유 URI(웹 주소)를 발급받아 PC 및 모바일에서 언제 어디서나 접속할 수 있습니다.

## 🚀 GitHub Pages로 무료 인터넷 URI(주소) 배포하기

GitHub Pages를 이용하면 별도의 웹 서버나 비용 없이 나만의 고유 인터넷 웹 주소(`https://<내아이디>.github.io/macro-dashboard/`)를 발급받을 수 있습니다.

### 방법 1. Git 터미널을 이용한 1분 배포 (추천)

1. **GitHub 저장소(Repository) 생성**
   - [GitHub.com](https://github.com)에 로그인합니다.
   - 우측 상단 **`+`** 아이콘 &rarr; **`New repository`**를 클릭합니다.
   - Repository name에 `macro-dashboard` (또는 원하는 이름)을 적고 **`Public`**을 선택한 뒤 **`Create repository`**를 누릅니다.

2. **로컬 터미널에서 코드 푸시하기**
   맥북의 **터미널(Terminal)**을 열고 아래 명령어를 순서대로 복사하여 실행합니다:
   ```bash
   cd /Users/insooshin/Desktop/macro-dashboard
   git init
   git add .
   git commit -m "Initial commit: Global Macro 5x3 Dashboard"
   git branch -M main
   # 본인의 GitHub 사용자명으로 아래 주소를 변경해주세요:
   git remote add origin https://github.com/<내_깃허브_아이디>/macro-dashboard.git
   git push -u origin main
   ```

3. **GitHub Pages 활성화**
   - GitHub 저장소 웹 페이지의 상단 메뉴 중 **Settings(설정)** 탭을 클릭합니다.
   - 좌측 메뉴에서 **Pages**를 클릭합니다.
   - **Build and deployment &rarr; Branch** 설정을 `None`에서 **`main`**으로 바꾸고 폴더는 **`/ (root)`**로 둔 뒤 **`Save`**를 누릅니다.
   - 약 1~2분 후 페이지 상단에 녹색 체크와 함께 **`Your site is live at https://<내아이디>.github.io/macro-dashboard/`** 링크가 나타납니다!

---

### 방법 2. 웹 브라우저에서 마우스 드래그앤드롭으로 업로드하기

1. GitHub에서 `macro-dashboard` 저장소를 생성합니다.
2. 새 저장소 화면 중간의 **`uploading an existing file`** 링크를 클릭합니다.
3. 맥북 바탕화면에 있는 `macro-dashboard` 폴더를 열고 그 안의 파일들(`index.html`, `styles.css`, `dashboard.js`, `chart-engine.js`, `data-store.js`, `README.md`)을 마우스로 끌어다 놓습니다.
4. 하단의 **`Commit changes`** 버튼을 누릅니다.
5. 저장소 **Settings &rarr; Pages**에서 `main` 브랜치를 선택하고 저장하면 완료됩니다!

## 💬 카카오톡 및 이메일 전송 기능 활용법

### 1. 카카오톡 전송
- 대시보드 상단의 **[카카오톡 전송]** 노란색 버튼을 클릭합니다.
- 스마트폰 브라우저에서는 공유 창이 열려 **카카오톡 친구나 나에게 보내기, 단체방을 바로 선택**하여 보낼 수 있습니다.
- PC 브라우저에서는 실시간 금리, 환율 요약 브리핑과 대시보드 링크가 자동으로 담긴 안내창이 뜨며, **[복사하기]**를 눌러 카카오톡 대화방에 바로 `Ctrl+V` (또는 `Cmd+V`) 붙여넣기 하실 수 있습니다.
- *공식 카카오톡 피드 카드 연동*: `developers.kakao.com`에서 무료 발급받은 JavaScript 키를 `Kakao.init('키')`에 등록하시면 이미지와 버튼이 포함된 카카오톡 카드 형태로 자동 발송됩니다.

### 2. 이메일 전송
- 상단의 **[이메일 전송]** 버튼을 클릭하면 사용하시는 이메일 프로그램(Outlook, Apple Mail, Gmail 등)이 자동으로 실행됩니다.
- 제목과 본문에 오늘 날짜 기준 주요 금리, 원/달러 환율, 기준금리 현황 및 50년 차트 대시보드 링크가 정돈된 텍스트 형태로 자동 작성되어 있어 수신자 이메일 주소만 적고 바로 발송하실 수 있습니다.

## 📱 스마트폰 홈 화면에 앱처럼 추가하기 (PWA 모드)

발급받은 GitHub Pages 링크(`https://<내아이디>.github.io/macro-dashboard/`)를 스마트폰으로 열면 마치 모바일 주식/금융 앱처럼 설치하여 사용하실 수 있습니다:

- **아이폰 (Safari)**: 하단 공유 아이콘 &rarr; **'홈 화면에 추가'**
- **갤럭시/안드로이드 (Chrome)**: 우측 상단 점 3개 메뉴 &rarr; **'홈 화면에 추가'** 또는 **'앱 설치'**

스마트폰 바탕화면에 생성된 아이콘을 누르면 주소창 없이 전체화면으로 매일 실시간 매크로 지표를 확인하실 수 있습니다.
